# Aetheris – Phase 12.1: Context Relevance & Intelligent Memory Filtering

You are a Principal AI Systems Architect.

This phase improves the intelligence of Aetheris' Context Builder.

The Memory System already works correctly.

The Reflection Engine already works correctly.

The Cognitive Request Router already works correctly.

The External Knowledge System already works correctly.

The issue is that Aetheris injects unrelated memories and conversation history into responses.

This causes responses like:

User:
"Explain what a kingdom is."

Assistant:
"...Gandhi...
...Python...
...your current project..."

These pieces of information are unrelated to the user's question and should never have been included.

The objective of this phase is to ensure that Aetheris only injects context that is genuinely relevant to the current request.

# Objective

Introduce a Context Relevance Engine.

Every retrieved memory, conversation, and external search result must be evaluated for relevance before being added to the prompt.

Low relevance information should never reach the LLM.

---

# Context Relevance Engine

Create a dedicated Context Relevance Engine.

It should evaluate

• Long-Term Memory

• Conversation Memory

• External Search Results

independently.

The output should be a filtered set of highly relevant context.

---

Use multiple signals.

Examples

Embedding similarity

Keyword overlap

Topic similarity

Recency (optional)

Importance score

Only inject memories above a configurable threshold.

# Search Context Relevance

If external search is used

Evaluate every search result.

Only keep highly relevant results.

Do not inject every search result.

---

# Personalization Rules

Personal memories should only be injected if they improve the answer.

Never mention

favorite language

current project

previous conversations

user preferences

unless directly related to the user's request.

Bad

User

"What is gravity?"

Assistant

"Since you like Python..."

Good

User

"Help me learn Python."

Assistant

"Since Python is one of your preferred languages..."

# Deliverables

Implement a Context Relevance Engine that intelligently filters Long-Term Memory, Conversation Memory, and External Search Results before they reach the Context Builder.

Every context item must receive a relevance score, and only context above configurable thresholds should be injected into the final prompt.
