# Aetheris – Phase 11.3: External Knowledge Integration with Cognitive Reasoning Engine

You are a Principal AI Systems Architect.

This phase integrates the existing External Knowledge Search Pipeline into Aetheris' Cognitive Reasoning Engine.

Do NOT redesign the architecture.

Do NOT modify the existing Memory System.

Do NOT modify the Reflection Engine.

Do NOT modify the Context Builder.

Do NOT modify the Prompt Builder.

Do NOT modify the LLM Provider Layer.

Do NOT modify the External Knowledge Provider architecture.

Everything implemented in previous phases is stable and must remain backward compatible.

# Objective

The Cognitive Reasoning Engine should intelligently decide whether a user's request requires external knowledge.

If external knowledge is required, it should execute a search using the existing Search Pipeline and provide the retrieved information to the LLM.

This decision must happen automatically.

No user action should be required.

---

# Decision Layer

Before building the final prompt, the Reasoning Engine must classify every request into one of two categories.

Category A

No external knowledge required.

Examples

- Explain binary search.
- What is polymorphism?
- Reverse a linked list.
- Write a Java program.
- Explain machine learning.

These should behave exactly as they do today.

No search should occur.

---

Category B

External knowledge required.

Examples

- Latest FastAPI version
- Today's weather
- OpenAI latest news
- NVIDIA stock today
- IPL points table
- Python 3.14 release notes
- Recent AI announcements
- Current Prime Minister of...
- Latest React version

These should trigger the Search Pipeline.

---

# LLM Instructions

When external knowledge is available, instruct the LLM to

- prioritize retrieved information
- combine it with its own reasoning
- admit uncertainty if the search results are insufficient
- never fabricate facts that are absent from both memory and search results

---

# Search Failure Handling

If the search fails

Continue the conversation.

Do not terminate the request.

The LLM should answer using its own knowledge.

Log the failure.

Never expose internal errors.

Deliverables

Integrate the existing Search Pipeline into the Cognitive Reasoning Engine by introducing an automatic decision layer that determines when external knowledge is required.

When triggered, the system should execute the existing Search Pipeline, inject normalized search results into the Context Builder, and allow the LLM to generate responses using both retrieved information and its own reasoning.

The implementation must preserve the current architecture, remain provider-independent, and avoid introducing ranking, summarization, caching, or other optimization features.
