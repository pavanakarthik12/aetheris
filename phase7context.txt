# Design Principles

The Reasoning Engine must NOT generate answers.

It should only make decisions.

The LLM remains responsible for generating natural language.

The Reasoning Engine decides

- what information is needed
- whether memory is needed
- whether clarification is required
- whether reasoning is simple or complex
- whether the request should proceed immediately

# Module 7 – Response Verification

Before returning an answer,

verify

Did the response answer the question?

Did it follow user instructions?

Does it contradict memory?

Is it internally consistent?

Is required information missing?

If verification fails,

regenerate once or request clarification.

# Deliverables

Implement a Cognitive Reasoning Engine that sits between the Cognitive Request Router and the Context Builder.

The engine should analyze intent, classify complexity, decompose tasks, decide which memory layers are required, determine whether clarification or planning is necessary, verify responses before delivery, and expose a debug-only cognitive trace.

The implementation should preserve the existing architecture while making Aetheris reason about requests before generating responses.
